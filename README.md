# CampusRide
Projekt neve: Campus Ride

Projekt célja: Közösségi telekocsi és járatmegosztó platform diákoknak és munkavállalóknak, amely megkönnyíti a munkába, egyetemre és egyéb helyekre való eljutást, csökkentve a költségeket és a környezeti terhelést.

Platform: Webes alkalmazás 

Technológiai stak (javaslat): HTML5, CSS3 (Tailwind CSS / Bootstrap), JavaScript (ES6+), Node.js / Firebase / LocalStorage (backend/adatkezelés)
